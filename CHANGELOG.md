## [Unreleased]

### Added
- Initial actor system with Fiber and Swoole runtimes
- Supervision trees with one-for-one and all-for-one strategies
- Persistence and event sourcing with in-memory, DBAL, and Doctrine backends
- Multi-process clustering via Swoole
- Psalm plugin for generic actor type inference
- Symfony Messenger bridge (`nexus-messenger`): MessengerActorRef/MessengerGateway producers, supervised ReceiverActor with backpressure-aware ack, pluggable MessageRouter, Nexus-backed Messenger serializer, and LifecycleWatchdog worker recycling
- Symfony Console runners (`nexus-messenger-console`): `nexus:messenger:consume` and `nexus:messenger:produce` commands with limit/memory/time watchdog wiring
- Threaded Swoole console adapter (`nexus-messenger-console-swoole`): `nexus:messenger:consume-threads` command using the Swoole worker pool; each thread owns an independent transport connection and actor system; limits are per-thread
- Broker request/reply (`nexus-messenger`): `MessengerActorRef::ask()` enabled via `AskSupport` (wired with `MessengerBridge::askSupport()`); `TransportReplyChannelFactory` with Ephemeral/DeleteOnShutdown/Persistent lifecycle; `MapReplySenderLocator` for SSRF-safe reply routing; `ReceiverActor` process-ack path with configurable `askPendingTimeout`; interop via `X-Nexus-Correlation-Id` / `X-Nexus-Reply-To` headers
- Msgpack codec (`nexus-serialization-msgpack`): `MsgpackCodec` with dual-backend dispatch — native `ext-msgpack` when available, pure-PHP `rybakit/msgpack` fallback; constructor-injectable backend selection for testing
- Network value objects (`nexus-core`): `Net\Host` (IPv4/IPv6 literals + RFC 1123 hostnames; `isIp()`/`isIpv6()` classification) and `Net\Port` (0–65535, port 0 = OS-assigned) — pure PHP, no new dependencies, reusable across cluster, cluster-tcp, and future http packages
- Runtime primitive (`nexus-runtime`): `Runtime::defer(callable): void` — fire-and-forget async execution in the runtime's own context (fiber/coroutine/step), for one-shot work that needs neither a tracked spawn ID nor a timer delay; implemented across Fiber, Swoole, and Step runtimes
- Serialization observability (`nexus-observability-serialization`): `TracingMessageSerializer` decorator with Internal spans, `nexus.serialization.operations` counter, `nexus.serialization.bytes`/`nexus.serialization.duration` histograms, `nexus.serialization.failures` counter, and optional PSR-3 failure warning; zero-overhead pass-through when observability is disabled and no logger is wired
- TCP cluster scaffold (`nexus-cluster-tcp`): `NodeEndpoint` host/port value object with `fromString()` port-range validation, `EndpointResolver` contract with immutable `MapEndpointResolver` and mutable `MutableEndpointRegistry`, and `ClusterTopology` configuration (bind/advertise endpoints, seeds, heartbeat/gossip intervals, phi threshold, reconnect backoff, optional TLS)
- TCP cluster full implementation (`nexus-cluster-tcp`): `ClusterNode::boot()` wires Swoole TCP mesh (auto-selects `SwooleMeshTransport` with ext-swoole, falls back to `LoopbackMeshTransport` for tests); gossip-based membership with `MembershipActor`; Hayashibara phi-accrual failure detection (gossip frames double as heartbeats; `maxNoHeartbeat` 10 s, `phiThreshold` 8.0, `phiSampleSize` 200, `phiMinStdDev` 500 ms); location-transparent `ClusterRef<T>` with `tell()` (local short-circuit or remote MessagePack frame) and `ask()` (correlation-ID round-trip via `TcpAskRegistry`, returns `Future`); graceful `shutdown()` broadcasts a Leave frame so peers skip the phi-accrual wait; PSR-14 membership events (`NodeUp`, `NodeDown`, `NodeSuspected`, `PeerConnected`, `PeerDisconnected`); full observability: `cluster.send`/`cluster.ask`/`cluster.handshake` OTel spans with W3C trace-context propagation, seven `nexus.cluster.*` metrics, PSR-3 structured logging; optional TLS via `TlsConfig`; `ClusterTopology::withFailureDetection()` for all five phi-accrual knobs
- TCP cluster wire hardening (`nexus-cluster-tcp`): frame decode is registry-strict — a remote peer can no longer name an arbitrary class on the wire to force its instantiation (unregistered types are rejected, not passed through as literal class names); `clusterName` and protocol version are checked synchronously at handshake parse time so a peer from a different cluster can never have its messages routed to local actors; TLS clients now enforce SNI hostname verification and reject self-signed certificates when `verifyPeer` is on. The C1 trust model (mutually trusted network; `clusterName` is not authentication) is documented explicitly — peer authentication and endpoint allowlisting remain planned hardening
- TCP cluster inbound DoS guards (`nexus-cluster-tcp`): concurrent accepted inbound links are capped (`maxInboundLinks`, default 1024) and an accepted link that never completes a handshake is closed after `handshakeTimeout` (default 10 s) — both tunable via `ClusterTopology::withInboundLimits()`; complements the already-bounded endpoint registry and Leave-dedup set. A Swoole recv timeout is no longer misread as a peer disconnect (`SwoolePeerLink`), which had let a mutual-seed mesh churn its links and falsely mark healthy peers Down
- TCP cluster load-safety fix (`nexus-cluster-tcp`): concurrent socket writes on a peer link are now serialized through a per-link coroutine mutex. Swoole forbids two coroutines writing the same socket at once and `sendAll()` suspends when the send buffer fills, so under sustained load an app send and a gossip/heartbeat send could collide and crash the process — now impossible. Uncovered and quantified by the new cluster-tcp throughput/latency benchmark and whole-machine saturation harness under `tests/Performance`, documented in the "Cluster TCP benchmarks" guide
- Native msgpack in the Docker images: `ext-msgpack` (pecl 3.x) is now installed in both base stages, so every container (fiber, swoole, full) gets the native backend that `MsgpackCodec` auto-detects — roughly halving raw pack/unpack cost versus the pure-PHP fallback and lifting end-to-end cluster throughput a further ~14% (1 KB tells 73.9K → 84.1K msg/s per core; machine-wide ~946K msg/s). `MsgpackCodec::unpack` now silences the extension's PHP warning on malformed/trailing bytes — untrusted network input must surface as the existing exception, not log noise
- TCP cluster membership event dedup + reachable refutation (`nexus-cluster-tcp`): a 16-node mesh soak showed one transient suspicion echoing into 25–133 events per observer. Two fixes: `MembershipEventDeduplicator` (actor-confined) suppresses re-announcements per (peer, incarnation) — older-incarnation echo always, repeats of the announced status always, post-Down readmission churn for a 30 s quiet period — while never losing a net state change (a recovery NodeUp always publishes); and gossip targets now include SUSPECT members, because a node every peer had marked Suspect received no gossip at all, could never see itself suspected, and its incarnation refutation was unreachable (persistent Suspect/Up flapping, downs never healing). Post-fix mesh run: zero Downs, all views heal, each real episode announced once per observer; 16/16 distributed soak PASS with the documented saturated-links phi tuning
- TCP cluster hot-path tuning (`nexus-cluster-tcp`): profiling-driven, 2.3× message throughput and roughly half the ask latency. `MessagePayloadCodec` packs/unpacks the per-message envelope directly (the Valinor TreeMapper had been 38% of the whole per-message budget for a fixed six-field VO; wire-compatible, strictly validated at the trust boundary — user message bodies stay on the generic Valinor path). `LivenessThrottle` coalesces per-frame liveness signals to one observation per peer per phi sample interval (50 ms), which also removes a reliability hazard: under sustained traffic the membership mailbox no longer floods with stale beats that delayed gossip/failure detection exactly when the cluster was busiest. Loopback benchmark: 1 KB tells 31.6K → 73.9K msg/s per core, ask p50 69 → 35 µs, machine-wide plateau ~315K → ~820K msg/s (~800 MB/s) on 12 P-cores; per-stage attribution reproducible via `tests/Performance/cluster_tcp_hotpath.php`
