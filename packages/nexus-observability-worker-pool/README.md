# nexus-actors/observability-worker-pool

Nexus worker-pool observability — tracing transport decorator that propagates trace context across worker threads and records transport metrics.

> **Read-only subtree split** of [nexus-actors/nexus](https://github.com/nexus-actors/nexus).
> Report issues and send pull requests to the monorepo — this repository only receives
> automated pushes and release tags.

## Installation

```bash
composer require nexus-actors/observability-worker-pool
```
