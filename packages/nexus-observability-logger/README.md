# nexus-actors/observability-logger

Nexus logs↔traces correlation — a RecordProcessor that stamps active-span trace/span ids onto log records.

> **Read-only subtree split** of [nexus-actors/nexus](https://github.com/nexus-actors/nexus).
> Report issues and send pull requests to the monorepo — this repository only receives
> automated pushes and release tags.

## Installation

```bash
composer require nexus-actors/observability-logger
```
