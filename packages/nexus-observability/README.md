# nexus-actors/observability

Nexus observability contracts — vendor-neutral tracing, metrics, and context-propagation interfaces with no-op defaults.

> **Read-only subtree split** of [nexus-actors/nexus](https://github.com/nexus-actors/nexus).
> Report issues and send pull requests to the monorepo — this repository only receives
> automated pushes and release tags.

## Installation

```bash
composer require nexus-actors/observability
```
