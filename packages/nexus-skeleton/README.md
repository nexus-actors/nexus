# My Nexus App

A project built on the [Nexus actor system](https://nexusactors.com) for PHP 8.5+.

## Quick start

**1. Start services**

```bash
docker compose up -d
```

**2. Run the actor system**

```bash
docker compose exec app php bootstrap.php
```

**3. Run the tests**

```bash
docker compose exec app vendor/bin/phpunit
```

## Structure

```
src/Actor/      — Actor definitions
src/Message/    — Message value objects (readonly classes)
src/Http/       — HTTP handlers and routes (if HTTP was selected)
src/Persistence/— Persistent actor examples (if persistence was selected)
tests/          — PHPUnit tests (StepRuntime for deterministic execution)
bootstrap.php   — Application entry point (generated by installer)
bin/console     — Symfony Console CLI entry point
```

## Configuration

Copy `.env.example` to `.env` and adjust for your environment:

```bash
cp .env.example .env
```
