# nexus-actors/maker

Code generators (make:actor, make:message) for Nexus skeleton projects.

> **Read-only subtree split** of [nexus-actors/nexus](https://github.com/nexus-actors/nexus).
> Report issues and send pull requests to the monorepo — this repository only receives
> automated pushes and release tags.

## Installation

```bash
composer require --dev nexus-actors/maker
```

Ships `make:actor` (types: handler, functional, stateful, event-sourced, durable-state)
and `make:message` — auto-registered by the [skeleton](https://github.com/nexus-actors/skeleton)'s
`bin/console` when installed.
